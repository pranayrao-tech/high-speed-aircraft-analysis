# ✈️ High-Speed Aircraft Analysis

This project compares the performance of two of the fastest aircraft ever built:

- SR-71 Blackbird  
- MiG-25 Foxbat  

---

## Features
- Speed vs Altitude simulation  
- Mach number calculation  
- Engineering-based exponential modeling  

---

## Tools Used
